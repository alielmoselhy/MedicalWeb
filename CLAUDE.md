# MedicalWeb

A study graph of diseases (causes → mechanisms → findings → outcomes) built for the LMC Syllabus 2026.

**Before drafting or editing any disease data, read `docs/drafting-protocol.md` and follow it step by step.** Then read `docs/concepts-<system>.md` for the system you're working on.

Non-negotiables:
- Agree structural changes with the owner first.
- Cite only pages you have read.
- Paraphrase; never copy from the books.
- `status: draft` on every new file.
- Draft two batches at a time, then stop and report.
- Never commit or publish unless asked. `Resources/` is private.

Check your work with `npm run build:data && npm test && npm run build`.
